# Закреплённые базы маршрутизации

Публичные снимки GeoIP/Geosite из проверенного alpha5 включены в исходники,
поскольку старые датированные релизы источника могут удаляться. Чистая сборка
silikbox не обращается к API последних релизов Geo-баз.

| Файл | Источник и версия | SHA-256 распакованной базы |
| --- | --- | --- |
| geoip.db.xz | SagerNet/sing-geoip,20260112 | 7b6348b4dad36a6b0c62f06f8f69cb00b2f438ee96dbae739f49d0ac387ad42a |
| geosite.db.xz | SagerNet/sing-geosite,20260208092911 | 33878593fe0af4a35093364909174520ae2351db6e4e8d317d4435ebf73d6cba |

Лицензии источников сохранены в LICENSE.geoip и LICENSE.geosite.
`tools/prepare_assets.py` проверяет распакованные байты и переносит файлы в
игнорируемый каталог Android assets. Это содержимое приложения, не личные данные.
