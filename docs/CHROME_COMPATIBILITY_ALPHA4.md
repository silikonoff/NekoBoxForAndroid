# Исторический этап alpha4: совместимость Chrome/REALITY

Состояние на02.11.2026. Старое ядро удаляло X25519MLKEM768 из ChromeHello.
Безусловное сохранение такого поведения несовместимо с новым Xray, требующим
hybrid share. На физическом Android часть современных Hello не проходила,
а вариант Edge работал. Одинаковое поле fingerprint не означало одинаковые байты.

В alpha4 реализовано обнаружение: modernHello первым, legacyChrome после ошибки
или задержки1сек, отдельный сокет, обязательная REALITYMAC, закрытие проигравшего
сокета и кэш режима только в памяти outbound. Явный opt-out сохранялся.

Alpha4 принят на TECNO/Android14 с прежней версией сервера. После обновления Xray
возник новый отказ. Этот исторический результат не означает приёмку актуальной
связки. Нынешний механизм описан в CHROME_COMPATIBILITY_ALPHA5.md.

MTU/TUN/socket-binding/handshake-mutex не объяснили отказ и не вошли в исправление.
Конкретный DPI или узел потери пакетов не установлен.
