# Журнал версий

## silikbox 1.0.0-alpha2 — 04.11.2026

- Окончательное название продукта — **silikbox**, по решению владельца.
- Переименованы репозиторий, ярлык приложения, новая S-иконка, APK/CI-артефакты и метка ядра.
- Новый README с матрицей протоколов, установкой, возможностями и баннером.
- Исправлена ссылка на справку по внешним плагинам.
- VersionCode265; пакет и сертификат сохранены для обновления наших прежних сборок.
- VPN-логика, поля профилей и алгоритм REALITY остаются прежними.

## NickMadBox1.0.0-alpha1 — 04.11.2026

- Собственное название NickMadBox и репозиторий silikonoff.
- Русский интерфейс по умолчанию, удалены китайские ресурсы приложения.
- Собственные ссылки поддержки/обновлений, сохранены лицензии исходных авторов.
- Пакет и локальный сертификат сохранены для обновления наших alpha.
- Включены закреплённые libneko/gomobile; сборка без старых репозиториев NekoBox.
- Автоматическая проверка и неподписанный артефакт CI без личных ключей.
- Поведение ядра соответствует принятому alpha5; изменена метка версии.
- Отчёты проверки этой сборки публикуются в GitHub Actions и в её релизе. Историческая приёмка ядра не заменяет проверку новой оболочки.

## NekoBox SB alpha5 — 03.11.2026

Автоматический компактный TLS1.3 Hello для VLESS TCP/REALITY, ML-KEM/X25519,
MAC-проверка, запасные варианты и выбор только после аутентификации.
На TECNO/Android14 приняты импорт, полный VPN, DNS/HTTPS,8параллельных запросов,
1МиБ,перезапуск,Wi-Fi/мобильная сеть. Конкретный сетевой фильтр не определён.

## alpha1–alpha4 — 02–03.11.2026

Перенос Android-моста, конфигурации и старых функций на sing-box1.14.4;
отдельный пакет, синяя тема, иконка щита и исследования REALITY.
Исторические результаты не заменяют проверку текущей версии.
